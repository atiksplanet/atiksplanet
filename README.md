### Home Care Monitor camera plugin

Led a **four-engineer team** developing the camera plugin for SmartThings iOS. My work included live streaming with WebRTC and RTSP, playback and history flows, camera settings, and data handling with Core Data caching and pagination.

Contribute to the connectivity layer beneath SmartThings iOS. Work includes version-aware subscriptions, caching behavior, diagnostic APIs, callback handling, BLE onboarding, network-change recovery, native-wrapper lifetimes and SDK delivery.

These are employer projects. I describe my contributions at a high level; proprietary source code and internal project records are not shared here.
